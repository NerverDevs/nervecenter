# NerveCenter 产品介绍

NerveCenter（https://nvcenter.cc）把你在各个 new-api、sub2api 中转站上的账号接到一处：余额、密钥、用量、倍率和提醒，都在一个控制台里。

## 为什么做它

做中转站的站长，手上通常有一串上游账号。每个面板都要单独登录：查余额要一个个点开，Key 散在各处，倍率调了不知道，余额见底往往是用户报错才发现。

为了让站长在一个地方管好自己的上游，我们做了 NerveCenter。账号接进来以后，余额、密钥、调用记录和分组倍率由我们定时同步；新建、停用 Key 这类操作，也直接在这里做。在好几个中转站有账号的普通用户，同样用得上。

## 它能帮你做什么

### 渠道接入

你在某个面板上的一个账号，在这里叫一个“渠道”。添加时粘贴面板地址，系统会识别它是 new-api 还是 sub2api，识别不出来可以手动选。

nvcenter.cc 目前用“从浏览器复制登录（F12）”接入：在你自己的浏览器里正常登录面板，验证码照常完成，再按步骤把登录凭据复制过来。不用装任何东西，每一步都有图文教程。

- new-api 有三种获取方式：
  - 一行命令 + 面板密码（推荐）：在面板标签页的控制台运行一行命令，输入一次面板密码，自动生成访问令牌并复制好。浏览器保持登录，令牌 180 天后过期，到时重新授权即可。
  - 复制 Cookie：不需要密码，但复制后要立刻清除网站数据。
  - 在面板里手动创建访问令牌：不用开发者工具，按教程勾选权限后粘贴过来。
- sub2api：在面板标签页的控制台运行一行命令复制登录凭据，立刻清除网站数据，再粘贴回来。

添加时可以选“仅自己”或“团队共享”。连接后首次同步一般要一两分钟，还会回溯一段历史用量。

### 余额总览

“中控台”汇总当前工作区的渠道：总余额、今日和近 7 天消耗、近 14 天消耗曲线、30 天余额趋势、近 7 天热门模型，也可以按平台分开看。

“需要处理”一栏列出需重新授权、余额不足、凭据即将过期、同步出错、上游故障的渠道，点进去就能处理。

### 密钥管理

不登录面板，也能管上游的 Key：

- 新建：名称、分组、额度（美元，或不限）、过期时间，可选 IP 白名单。
- 修改、停用、重新启用。
- 显示明文：有的站点限制查看次数，会先告诉你还剩几次、什么时候重置。
- 删除：在上游删除这把 Key，用它的应用会立即失效。

“API 密钥”页汇总你能看到的所有 Key，可以按渠道、平台、状态、分组筛选和搜索，还显示每把 Key 所在分组的倍率。面板上原有的 Key，会在同步时自动出现。

### 用量与日志

“用量日志”页按天、按模型统计请求数和费用，下面是逐条调用明细：时间、模型、密钥、分组、输入/输出 token、费用、耗时。

可以按日期（UTC）、渠道、模型、密钥名称、分组筛选，筛选结果能导出为 CSV 或 NDJSON。调用记录大约每 10 分钟同步一次。

### 倍率与价格

每个渠道都有“价格与倍率”页。

- 分组倍率：只列你能用的分组，显示你本人实际适用的倍率。站长单独给你设了倍率，就以那个为准。
- 模型价格：换算成每 1M token 的输入价和输出价，按次计费的显示每次价格。选一个分组，就能看到这个分组的实际价格。

各个站点用同一种口径，比价就方便了。

### 渠道简报与健康

面板本身不保留倍率和模型的变更历史，所以我们默认每 10 分钟比对一次分组倍率、每 30 分钟比对一次模型列表，自己记下来。频率可以由平台管理员在“平台设置 → 同步频率”里调整；需要逐个分组读取模型的面板，模型最多每 6 小时读一次。

- 简报：近 7、30、90 天的时间线。哪个分组涨价、降价，哪些分组新增、下线，哪些模型上架、下架，一眼看清。
- 健康：读取面板自己统计的各模型成功率、平均耗时、首字耗时、输出速度；sub2api 读取面板的渠道监控数据，比如可用率、成功率。数字反映整个面板，不只是你的请求。我们不会用你的密钥发测试请求，不会产生费用。

> 简报里的几条记录（示例）：今天 · 涨价 · default 分组倍率上调 ×1 → ×1.2；昨天 · 新分组 · 新增分组 vip；昨天 · 上架 · vip 分组上架 3 个模型。

### 模型比价

控制台的“模型比价”页：同一个模型，在你的各个渠道上各要多少钱、稳不稳，放在一起比，挑哪条线路心里有数。

- 价格：站点公布的模型价 × 这个渠道你自己的分组倍率，换算成每 1M token 的输入价和输出价，口径和“价格与倍率”页一致。
- 稳定性：来自面板自己的健康统计，比如成功率和平均耗时。没有健康数据的渠道会注明，不会当成 0 分。
- 推荐：每类模型挑出最便宜、最稳、最划算的渠道；模型列表可以排序、按渠道筛选，也能导出 CSV。

只算你在当前工作区能用的渠道，也可以只看自己绑定的；每个渠道只用它自己的分组和倍率，不借用别人的。不会用你的密钥发测试请求。

### 通知提醒

- 消息中心：右上角的铃铛。余额预警、渠道异常、倍率与模型变化、安全提醒和平台公告都在这里，保留 180 天，可以筛选、标为已读。
- 推送渠道：Telegram 和 Webhook。Webhook 把带 HMAC-SHA256 签名的 JSON 发到你自己的 https 地址。每个 Telegram 聊天和 Webhook，还能单独挑选接收的类别。邮件通知即将开放。
- 通知设置页：“通知规则”决定提醒哪些事，“推送渠道”决定发到哪里。每一项都能分别开关站内、Telegram、Webhook。顶部可以搜索（比如输入“密钥”“余额”“登录”），按开关状态筛选，也能一键恢复默认。
- 余额提醒：在“余额”一组设一条提醒线（美元），你能看到的任一渠道跌破它就提醒你。不设提醒线，就不会收到余额提醒。
- 安全提醒：只针对你自己账号上的操作，比如新设备登录、改密码、开关两步验证、使用恢复码，以及 API 令牌、密钥、渠道和推送渠道的变动。每条都带时间、IP、设备和方式，每一项都能单独关掉。
- 及时：倍率、分组和模型的变化，检测到后几秒内就推送；余额不足、需要重新授权，在检查后 1 分钟内送达。

> 消息中心里的一条余额提醒（示例）：「hub.example.net」余额 $4.20，低于提醒线 $5.00

### Telegram 机器人

官方机器人是 @NerverCenter_bot。

- 连接：在“通知设置 → 推送渠道”点“连接 Telegram”，用手机扫码或点链接，按“开始”。连接码 10 分钟内有效，只能用一次。
- 菜单：发送 /menu，点按钮查看余额总览、我的渠道、今日用量、倍率变化，管理密钥，调整推送设置。
- 密钥：分步新建（名称、分组、额度、有效期）。停用、删除、查看完整密钥都要先确认；完整密钥以防转发消息发出，过一会儿自动删除。
- 推送设置：余额预警、渠道异常、倍率与分组、新模型、安全提醒、平台公告，六个开关。
- 机器人只响应私聊，权限和你在网站上登录时一样。改密码、开关两步验证或退出其他所有设备后，要回网站重新连接才能继续操作，通知照常收到。

### 团队协作

- 工作区：渠道和成员放在工作区里。注册时会建好第一个，之后可以新建，在顶部随时切换。
- 邀请：填对方邮箱、选角色（管理员、操作员、只读成员），生成一条邀请链接。链接只显示一次，需要你自己发给对方；对方用这个邮箱登录或注册后接受。
- 可见范围：“仅自己”的渠道只有你能用（密钥、用量、同步、重新授权），所有者和管理员只能看到名称、平台、状态和余额。“团队共享”的渠道，所有成员都能看到密钥列表和用量，所有者和管理员可以完全管理。
- 授权：其他成员要新建、修改密钥或查看明文，需要单独授权。可授予的权限有管理密钥、查看密钥明文、修改备注名。
- 成员离开时，他的私有渠道连同凭据和数据移到他的个人工作区，共享渠道留在原工作区。
- 所有者和管理员可以查看审计日志：绑定渠道、查看或修改密钥，都会留下记录。

### 账号安全

- 两步验证：用身份验证器扫码开启，同时拿到 10 个一次性恢复码，可以下载保存。
- 没有手机：开启时可以直接显示密钥，再打开 https://nvcenter.cc/tools/2fa ，粘贴密钥就能看到当前的 6 位验证码。验证码完全在你的浏览器里计算，密钥不会发送到任何地方，也不会保存。登录时的验证码页也有入口。
- 登录设备：查看每台在线设备，可以单独让某台退出，也可以“退出其他所有设备”。后者会同时吊销你所有的 API 令牌，并断开 Telegram 聊天的操作权限。
- 安全动态：登录、两步验证、改密码等记录，连同成功或失败的结果。
- 改密码时，“同时吊销所有 API 令牌”默认勾选，其他设备会退出登录。

### 个人 API 令牌

给脚本和自动化工具用，在“个人设置 → API 令牌”里创建。

- 权限范围按需勾选：只读、管理密钥、查看密钥明文、触发同步、修改渠道名称。
- 可以只绑定一个工作区。有效期 1 到 365 天，或者永不过期，默认 90 天。
- 令牌以 nct_ 开头，只在创建时显示一次。使用时放在请求头 `Authorization: Bearer nct_…`，工作区内的接口还要带 `X-Tenant-ID`。
- 令牌能做的永远不超过你本人。任何令牌都不能绑定、重新授权或删除渠道，不能管理成员和邀请，也不能改密码、两步验证和登录设备。

## 三步上手

1. 注册：打开 https://nvcenter.cc ，填邮箱、显示名称、密码（至少 10 个字符）和工作区名称，输入图中的 5 位数字验证码。注册后直接进入你的工作区。
2. 添加第一个渠道：“渠道 → 添加渠道”，粘贴面板地址，点“识别站点”，按页面上的步骤用 F12 复制登录，点“连接”。
3. 看中控台：一两分钟后，余额、密钥和用量就会出现。顺手设一条余额提醒线、连上 Telegram，再开两步验证，把恢复码存好。

## 支持的面板与限制

- 支持 new-api（能识别出的改版面板也支持）和 sub2api。其他面板会提示“该地址上没有找到支持的面板”。
- nvcenter.cc 目前只开放 F12 复制登录这一种方式。带验证码、人机验证的站点没有问题，因为登录在你自己的浏览器里完成。
- 我们无法代你完成通行密钥（Passkey）验证。只能用通行密钥验证的 new-api 账号，用不了“一行命令”，请改用复制 Cookie 或手动创建访问令牌。“一行命令”还要求账号设有密码；面板对密码加密时，页面要是 https。
- 部分 sub2api 站点会把登录和 IP、浏览器绑定，从你浏览器复制过来的登录，可能被站点撤销。这时需要重新授权。
- 登录失效或访问令牌到期时，渠道会标为“需重新授权”，同步暂停；重新授权后自动恢复。
- 面板没有某项功能时，会直接说明原因，不会莫名报错。每个渠道接入后会逐项检测，每天复检一次，也可以手动“重新检测”。检测规则按原版面板制定，个别改版面板可能判断不准。
- 健康数据只在较新版本的 new-api，或开了渠道监控的 sub2api 上才有。
- 有的面板限制日志的查询跨度，更早的历史可能回溯不全，页面上会注明。
- 用量导出单次最多 10 万行，超出的部分不会导出，请缩短日期范围分次导出。
- 本站暂未开通邮件：不能通过邮件找回密码，也不能通过邮件关闭两步验证。

## 安全与隐私

我们保存的内容：

- 你在 NerveCenter 的账号：邮箱、显示名称，密码只存 argon2id 哈希。
- 每个渠道的登录凭据。粘贴进来的内容只保留站点需要的那几项，其余丢弃。
- 同步来的数据：余额、密钥列表、调用记录、倍率和模型的变化。

我们怎么保护它：

- 上游凭据和查看过的密钥明文，入库前都用主密钥加密封装。每条上游凭据有自己的数据密钥，用 AES-256-GCM 加密。
- 平台管理员看不到你的上游凭据。管理员如需查看某把密钥的明文，只能逐把查看，要先通过两步验证，每次都记入审计。
- 绑定、查看明文、调整权限等敏感操作，先写审计再返回结果。审计不记录任何令牌和密码。
- 查看密钥明文有频率限制，默认还会给你发安全提醒。

不经过我们的东西：

- “一行命令”里的面板密码，只发给面板本身，不经过 NerveCenter。
- sub2api 的复制命令只读取当前页面的登录信息，复制到你的剪贴板，不会发出去。
- /tools/2fa 里的两步验证密钥，只在你的浏览器里计算，不发送、不保存。

从面板复制出来的登录凭据，作用和你本人登录一样。只把它粘贴到你信任的 NerveCenter。

## 常见问题

**要把面板密码交给你们吗？**
不用。“一行命令”里的密码只发给面板本身。我们保存的是访问令牌或登录凭据，不是密码。

**为什么复制完要清除网站数据，而不是点退出登录？**
之后由我们定时刷新这份登录。浏览器里如果还留着同一份，两边谁后刷新谁就失效。清除只删本机数据，不会通知面板；点“退出登录”会让面板把这份登录作废。用访问令牌的方式不需要清除。

**渠道显示“需重新授权”怎么办？**
在渠道页点“重新授权”，用同一个上游账号再复制一次。同步会自动恢复。

**余额和用量多久更新一次？**
默认情况下，余额每 5 分钟同步一次，调用记录大约每 10 分钟，分组倍率每 10 分钟、模型列表每 30 分钟比对一次，具体频率由平台管理员设置。急着看可以点渠道页的“立即同步”，每个渠道每分钟最多 2 次。

**“健康”页会花我的钱吗？**
不会。数字来自面板自己的统计，我们不会用你的 Key 发测试请求。

**忘了密码，或者验证器和恢复码都丢了？**
本站暂未开通邮件，没法自助找回，请联系本站运营方。开启两步验证后，一定要把恢复码存好。

**删除渠道会影响我在面板上的账号吗？**
不会，只删除我们这边的凭据和同步数据。如果是用访问令牌接入的，令牌在面板上仍然有效，请到面板的“安全 → 访问令牌”里撤销名为 NerveCenter 的那个。
